## 🍎 Estudo de JavaScript — Página de Produto

Projeto desenvolvido com o objetivo de praticar lógica e manipulação de elementos com JavaScript dentro de uma página HTML.

A estrutura visual e o CSS da página já estavam prontos. O foco do exercício foi implementar a interatividade utilizando JavaScript, principalmente através de eventos onclick e manipulação do DOM.

## 🎯 Objetivo

O principal objetivo deste projeto foi estudar como o JavaScript pode ser utilizado para controlar e modificar elementos de uma página HTML.

Durante o desenvolvimento, foram praticados conceitos como:

- Manipulação do DOM
- Seleção de elementos HTML
- Eventos onclick
- Alteração de textos através do JavaScript
- Alteração de imagens
- Manipulação de classes CSS
- Uso de arrays
- Estruturas condicionais
- Criação de funções
- Lógica de interação entre elementos da página
## ⚙️ Funcionamento

A página representa uma interface de produto inspirada em um Apple Watch.

A parte visual da página já estava desenvolvida. O exercício consistiu em utilizar JavaScript para adicionar comportamentos aos elementos.

Por exemplo, ao selecionar diferentes opções do produto, o JavaScript realiza alterações na página, como:

- Alteração da cor do produto;
- Alteração do tamanho selecionado;
- Troca das imagens;
- Atualização de informações exibidas;
- Alterações visuais conforme a opção escolhida.

Dessa forma, o projeto foi utilizado principalmente para entender como conectar ações realizadas pelo usuário com alterações nos elementos HTML através do JavaScript.

## 🛠️ Tecnologias utilizadas
- HTML5 — Estrutura da página
- JavaScript — Lógica e interatividade
- CSS3 — Estilização previamente disponibilizada

O CSS não foi o foco deste projeto. O objetivo principal foi praticar a lógica JavaScript aplicada a uma página HTML já estruturada.

## 🧠 O que foi praticado

Este projeto serviu como exercício prático para entender o funcionamento do JavaScript no navegador.

Um dos principais conceitos estudados foi o uso de eventos como:

- onclick

Através desses eventos, ações realizadas pelo usuário podem executar funções JavaScript e modificar elementos da página.

Exemplo simplificado:
<pre>
function alterarProduto() {
    // lógica para alterar elementos da página
}
</pre>
Esse tipo de interação ajudou a compreender a relação entre:
<pre>
Usuário
   ↓
Evento HTML
   ↓
JavaScript
   ↓
Manipulação do DOM
   ↓
Alteração da página
</pre>
## ▶️ Como executar

Não é necessário instalar dependências ou configurar um servidor.

Clone o repositório:

- git clone https://github.com/Guigo710/JS_pagina.git

Entre na pasta do projeto:

- cd JS_pagina/JS_página

Abra o arquivo:

- index.html

O projeto pode ser executado diretamente no navegador.
